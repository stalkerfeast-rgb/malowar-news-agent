# Правила разработки Malowar News Agent

- Перед изменениями прочитай README.md, ROADMAP.md и BUILD.md. После проверки обнови статус затронутой версии или задачи. Указывай среду, сценарий и результат.
- Продолжай от настоящих исходников 1.3.19. Сначала проверь состав архива и определи фактические команды сборки по исходникам. Импортируй исходный снимок отдельным коммитом после проверки файлов. Изменения поведения делай последующими коммитами.
- Сохрани проверенный перенос текста и фотографий из 1.3.18 и ручной резервный сценарий. При ошибке открытия редактора, неверном сообществе или неопределённом состоянии страницы остановись и дай пользователю продолжить вручную.
- VK Publisher может открыть редактор, заполнить текст, приложить фотографии и в будущем заполнить дату и время. Финальные «Опубликовать», «Запланировать» и подтверждение сохранения отложенной записи пользователь нажимает лично. Фоновая публикация, отправка через API и автоматическое подтверждение запрещены.
- Получай адрес сообщества VK из локальных настроек. Поддерживай смену сообщества владельцем без пересборки. Проверь, что автоматизация работает именно на выбранной странице. Обрабатывай отсутствие доступа и истёкшую авторизацию.
- Для компьютера владельца путь установки по умолчанию — `E:\Агент` при наличии диска E:. Сохраняй возможность указать другой путь. При обновлении сохраняй Data и фактический профиль Edge, где хранится сеанс VK. См. BUILD.md.
- GitHub-репозиторий публичный. Просматривай каждый подготовленный к коммиту файл. Токены, cookies, сеансы Edge, настройки пользователя, черновики, логи, базы, копии Data, экспорт VK и локальные установочные данные в Git запрещены. Проверяй исходники и установочные скрипты на встроенные ключи, пути профилей и идентификаторы, относящиеся к пользователю. В примерах используй вымышленные значения.
- Используй временный каталог и тестовые данные для сборки и локальных проверок. Фактический запуск на VK отмечай отдельно от тестов на локальной странице.
