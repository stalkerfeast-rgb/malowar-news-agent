# Сборка и проверка на Windows x64

## Команды из корня репозитория

Для Windows x64 нужен Go 1.23 или совместимая более новая версия. Node.js нужен для проверки JavaScript. Выполните в PowerShell:

```powershell
go test -count=1 ./...
go vet ./...
node --check app/awards_editor.js
.\build_all_windows.ps1
Get-FileHash -Algorithm SHA256 -LiteralPath .\Malowar_News_Agent_1_3_19_Setup.exe
```

`build_all_windows.ps1` собирает агент, обновлятор, деинсталлятор и установщик. Если нужен только агент, запустите `.\build_windows.ps1`. Для проверки браузерного сценария задайте `MNA_LIVE_CDP_TEST=1` и `MNA_CHROMIUM_PATH` с полным путём к Chrome или Chromium, затем выполните `go test -count=1 -run TestVKCDPOnLocalMock -v`. Этот тест использует локальную страницу. Проверка на VK выполняется отдельно.

## Сохранение рабочей установки

При переносе проверены Go-тесты и `go vet` на Windows x64 с Go 1.23.12, синтаксис JavaScript, локальный браузерный тест с Chrome и полная сборка установщика. Установка поверх рабочей версии и проверка на реальном VK ещё предстоят.

1. Закройте News Agent и окно Edge, которое он использует для VK. В исходниках 1.3.19 выделенный профиль задан как `%LOCALAPPDATA%\MalowarNewsAgent\VKBrowser`. Проверьте, существует ли он, и сохраните его при наличии. Используйте ту же учётную запись Windows. Перенос браузерной сессии на другой компьютер может потребовать повторного входа.
2. Сделайте локальные копии `E:\Агент\Data` и выделенного профиля Edge вне репозитория. Сохраните текущий установщик 1.3.18, чтобы можно было вернуться к нему. Если профиль обычный и общий для Edge, оставьте его на месте и используйте тот же профиль при проверке.
3. Сначала проверьте обновление в отдельной установке с тестовыми данными. Для обновления рабочей установки укажите существующий `E:\Агент`. Если диска E: нет, выберите другой путь. Установщик должен сохранять Data и профиль.
4. После запуска сравните наличие настроек, черновиков и медиа, убедитесь, что в Edge открывается нужное сообщество и сохраняется вход. При повреждении остановите приложение и Edge, сохранив отдельно данные после теста, затем верните рабочую версию и резервные копии.

## Ручная проверка VK

- Используйте одну одобренную тестовую новость с текстом, хештегами и двумя фотографиями. Проверьте целевое сообщество, затем нажмите «Открыть запись и заполнить VK».
- Убедитесь, что редактор действительно открылся, текст полный, фотографии прикреплены в исходном порядке, редактор открыт для ручной проверки. Проверьте, что в VK не появилась опубликованная или запланированная запись.
- Повторите ручной сценарий переноса из 1.3.18. Проверьте смену адреса сообщества через локальную настройку с разрешённым тестовым сообществом, а также поведение при отсутствии доступа.
- Когда будет реализована отложка, проверьте дату, время и часовой пояс в интерфейсе. Финальное сохранение запланированной записи выполняется вручную.
