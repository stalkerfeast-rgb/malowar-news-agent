MALOWAR NEWS AGENT 1.3.9 — КАК ОПУБЛИКОВАТЬ В GITHUB
===================================================

Ссылка для создания релиза (открывай, войдя в свой GitHub):
https://github.com/stalkerfeast-rgb/malowar-news-agent/releases/new

Официальный список релизов:
https://github.com/stalkerfeast-rgb/malowar-news-agent/releases

ВАЖНО: репозиторий пока содержит только README.md в ветке main, а в GitHub Releases
уже опубликована версия v1.3.8. Для автообновления достаточно выпустить новый Release
с двумя файлами обновления. Не нужно перезаливать код в main вручную.

ШАГ 1. Скачай этот пакет: Malowar_News_Agent_1_3_9_GitHub_Release_FINAL.zip.
ШАГ 2. Распакуй его в любую папку Windows.
ШАГ 3. Перейди по ссылке создания релиза выше.
ШАГ 4. Нажми «Choose a tag» / «Создать новый тег» и введи: v1.3.9.
ШАГ 5. Target/Target branch: main.
ШАГ 6. Title: Malowar News Agent 1.3.9 — Награды и редактор новостей.
ШАГ 7. Описание: скопируй RELEASE_NOTES_1_3_9_RU.txt из архива.
ШАГ 8. Перетащи В СЕКЦИЮ «Attach binaries by dropping them here» два файла:
  - Malowar_News_Agent_Update.zip
  - Malowar_News_Agent_Update.zip.sha256
НЕ прикрепляй вместо этих файлов только внешний GitHub_Release_FINAL.zip: программа
ищет строго два файла, указанных выше.
ШАГ 9. Убедись, что «Set as a pre-release» и «Save as draft» выключены.
ШАГ 10. Нажми «Publish release».

ПОСЛЕ ПУБЛИКАЦИИ
- Проверь, что оба файла доступны здесь:
  https://github.com/stalkerfeast-rgb/malowar-news-agent/releases/tag/v1.3.9
- В News Agent 1.3.8 зайди в «Настройки» → «Канал обновлений программы»
  и укажи: stalkerfeast-rgb/malowar-news-agent
- Сохрани настройки, затем нажми «Проверить обновления» / «Установить».
- Закрой News Agent, когда предложит, и дай обновлятору завершить установку.
- Если удобнее, установи 1.3.9 вручную через Setup_FINAL.exe в прежнюю папку.
- Перед ручной установкой сделай резервную копию папки Data.

ЗАМЕТКИ
- Сам GitHub Release здесь НЕ опубликован. Эти шаги предназначены для ручной загрузки.
- Этот выпуск уже включает доработки текста новостей, утверждённые награды и редактор
  обложек. Используй FINAL-пакет, а не более раннюю сборку 1.3.9 из предыдущего сообщения.
- SHA256 внутри файла .sha256 относится к внутреннему Malowar_News_Agent_Update.zip.
- Для хранения полного исходного кода отдельно можно использовать Source_FINAL.zip;
  автоматическое обновление через GitHub Releases НЕ требует публикации исходников.
