Malowar News Agent 1.3.14 — хотфикс токена VK (Windows)

1. Исправлено: ключ VK больше не исчезает при закрытии программы.
2. После однократного подключения хранится зашифрованно Windows DPAPI под текущим профилем (%APPDATA%\MalowarNewsAgent\Secrets\vk-token.dpapi).
3. Состояние очереди и черновики в Data не затрагиваются.
4. Кнопка «Забыть токен» удаляет сохранённый ключ.
5. Кнопка «Проверить доступ» проверяет через VK API право на загрузку фотографий (без публикации).
6. Группа VK: сохраните ID 211159240, если его ещё нет в настройках.

ВАЖНО: старые 1.3.12 не сохраняли токен нигде. Если программа уже закрывалась, получить старый ключ автоматически нельзя.
После установки 1.3.14 понадобится ЕДИНОЖДЫ скопировать ещё действующий токен из VK (если его нет в открытой сессии).
Токен нельзя присылать в чат или GitHub.

Установка:
- Закрой News Agent, сделай резервную копию Data.
- Запусти Setup 1.3.14 поверх старой папки или обнови через корректно опубликованный GitHub Release.
- В Настройках нажми «Подключить и сохранить», затем «Проверить доступ».
- После перезапуска токен должен восстановиться автоматически.
- Ошибка VK API 1116 может означать, что сам токен неверен или не имеет нужных прав: хранение её не исправляет.
