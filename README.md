# Malowar News Agent

Windows-приложение для отбора игровых новостей и подготовки записей VK. Эта ветка содержит импорт исходников 1.3.19 и рабочий контекст для разработки в Codex.

- **1.3.18** — версия исполняемого файла, на который указывает ярлык владельца. Номер подтверждён по встроенной строке интерфейса и метаданным установки. Перенос текста и фотографий в VK подтверждён владельцем.
- **1.3.19** — в прежней разработке добавлена кнопка «Открыть запись и заполнить VK». По отчёту из прежнего чата открытие редактора и перенос текста проверены в тестовом Chromium, а автоматизация на настоящем VK ещё ждёт проверки.
- **Дальше** — проверка 1.3.19 в VK, автоматическое заполнение времени отложки, отдельный раздел «Будущие релизы Steam».

В Codex или Work откройте локальную папку репозитория и начните задачу из неё. Правила работы лежат в [AGENTS.md](AGENTS.md), история решений и статус задач — в [ROADMAP.md](ROADMAP.md), сборка и проверка обновления — в [BUILD.md](BUILD.md).

Рабочая установка владельца — `E:\Агент`. Каталог разработки должен быть отдельным. Другому пользователю нужна возможность указать адрес своего сообщества VK в настройках. Финальное действие публикации или постановки записи в очередь выполняет человек в VK.
