MALOWAR NEWS AGENT 1.3.11
ОТЛОЖЕННЫЕ ЗАПИСИ VK • ХЭШТЕГ ИГРЫ • КАТАЛОГ MALOWAR AWARDS

НОВОЕ
1. VK: после нового РУЧНОГО одобрения проверенного поста агент назначает ближайший свободный слот по МСК и создаёт отложенную запись VK через wall.post с publish_date. По умолчанию включено, можно отключить в Настройках.
2. VK: отдельные статусы «В очереди VK», «Отправка», «В отложке VK», «Опубликована», «Проверь VK». При ошибке загрузки фото пост остаётся в локальной очереди с ручным повтором. При неизвестном результате wall.post автоматического повтора нет, чтобы не дублировать пост.
3. После подтверждённой публикации VK агент добавляет источники в первый комментарий. VK публикует отложенный пост автономно, но комментарий отправляется только при запущенном приложении и подключённом токене VK. Токен НЕ сохраняется на диск.
4. Заголовок игры обязательно появляется в одном из четырёх-пяти хэштегов, без пробелов и пунктуации. Например: Age of Wonders 4 -> #AgeofWonders4. Проверяется при одобрении; у новых AI-черновиков формируется автоматически.
5. Malowar Awards: каталог из 50 редакционных названий, три утверждённых PNG остаются без изменений. Ещё 47 позиций имеют статус «в очереди графики», поскольку их изображения не были утверждены. Из редактора можно загрузить утверждённый PNG для отдельной награды и использовать её на обложке. Можно добавлять новые идеи наград.
6. Пустая обложка больше не получает «Скрытую жемчужину» автоматически. Максимум три плашки на одном изображении, они перетаскиваются мышью.

СОВМЕСТИМОСТЬ
Сохраняются Data/state.json, изображения, все прошлые черновики, редакционные решения и результаты радара 1.3.10. Старые одобренные посты НЕ отправляются автоматически после обновления. Старые локальные задания не преобразуются в отложку VK без решения пользователя.

ВАЖНО О VK
Требуется токен с достаточными разрешениями wall и photos. Некоторые токены сообщества не поддерживают нужные методы; обычно потребуется пользовательский токен администратора с нужными правами. Никогда не добавляй токен в репозиторий или архив релиза.
Записи VK фактически выйдут в указанное время, даже если приложение закрыто. Если агент закрыт во время публикации, комментарий со ссылками появится после следующего запуска, подключения токена и подтверждения через API, если VK разрешает доступ.
Фактическая публикация в сообществе Malowar Gaming НЕ выполнялась при тестировании. Интеграционный тест использует имитацию ответов API.

УСТАНОВКА
1. Закрой текущую 1.3.10.
2. Сделай дополнительную копию папки Data (установщик тоже сохраняет резервную копию state.json перед обновлением).
3. Запусти Setup 1.3.11 в той же директории. Данные не удаляй.
4. Настройки > VK: включена опция «После одобрения создавать отложенный пост непосредственно в VK»; при необходимости подключи токен заново.
5. Проверь один тестовый материал в редакторе; после одобрения его создание в отложке будет настоящим действием VK. Для теста безопаснее сначала отключить настройку и проверить черновик.
