MALOWAR NEWS AGENT 1.3.12 — ИНСТРУКЦИЯ

Установка поверх существующей версии:
1. Закрой агент кнопкой «Выход».
2. Для перестраховки скопируй папку Data. Установщик также резервирует state.json в Data/updates/backups при обновлении ранее установленной версии.
3. Запусти Malowar_News_Agent_1_3_12_Setup.exe и выбери ТОТ ЖЕ путь, где установлена программа.
4. Проверь в шапке «Версия 1.3.12».
5. Настройки → укажи ID сообщества VK цифрами без минуса → включи «После одобрения создавать отложенный пост» → проверь часы публикаций МСК → сохрани.
6. Подключи токен VK с необходимыми правами на публикацию и загрузку фотографий. Токен хранится только в ОЗУ и после закрытия программы вводится снова. НЕ добавляй его в GitHub.
7. Открой подходящую новость → проверь текст, хэштег с названием игры и 3–7 официальных изображений → отметь проверку → «Одобрить». 
8. Открой «Отложка VK · статусы» для проверки результата: «Локальная очередь» означает, что VK ещё НЕ подтвердил размещение. «В отложке VK (ID получен)» означает, что VK вернул номер записи. «Опубликована в VK» и «Первый комментарий» отображаются отдельно.
9. Существующий старый одобренный пост можно отправить кнопкой «Отправить одобренный пост в отложку VK»; ничего не отправляется задним числом без действия.
10. Если сервер VK отклоняет права токена, исправь права и повтори. При статусе «Неясно: проверь VK» не повторяй публикацию вслепую.

ВАЖНО: отложенную запись VK опубликует автоматически в назначенный час, даже при закрытом агенте. Для добавления источников первым комментарием приложение должно снова работать с подключённым VK токеном. Фактические возможности и требования к токену зависят от настроек сообщества и разрешений API VK.
