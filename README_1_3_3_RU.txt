MALOWAR NEWS AGENT 1.3.3  (Windows 10/11 x64, бета)
=================================================

Установка поверх 1.3.2
----------------------
1. Сохраните редактируемые черновики. В программе нажмите «Выход».
2. Рекомендуется отдельно скопировать папку Data в безопасное место.
3. Запустите Malowar_News_Agent_1_3_3_Setup.exe и выберите папку
   ПРЕДЫДУЩЕЙ установки (с файлом .mna-install.json).
4. Новая версия сохраняет папку Data. Установщик создаёт резервную копию
   state.json в Data/updates/backups/setup-YYYYMMDD-HHMMSS.
5. Включите Ollama (qwen3:14b), если требуется локальная генерация.

Обложки
-------
- Для новых новостей Steam сначала проверяется официальный Library Hero,
  затем Steam Header, потом скриншоты. Для модов Workshop первым остаётся
  официальный preview-арт.
- «Найти официальный баннер → первым»: повторный поиск для старого поста.
  Если уже 7 картинок, последняя исключается из галереи, но не удаляется
  с диска. Перед действием требуется подтверждение.
- «★ Главная», стрелки и перетаскивание меняют порядок без потери источников.
- «Собрать обложку из официальных материалов»: локальная композиция
  1280x720 из первых двух загруженных изображений и названия игры. Это НЕ
  ИИ-генерация; требуется свободное место в галерее (меньше 7 картинок).
- Все изображения проверяются редактором перед публикацией, включая права.

Обновления
----------
- Обновлятор включён в УСТАНОВЛЕННУЮ версию 1.3.3.
- В «Настройки» укажите официальный GitHub-репозиторий релизов owner/repo.
  По умолчанию он ПУСТ: сервер обновлений пока не развёрнут.
- Кнопка «Обновления» проверяет GitHub Releases. Когда настроен репозиторий,
  проверка выполняется также при открытии и раз в сутки.
- Для установки будущей версии в публичном стабильном GitHub Release
  (например v1.3.4) должны присутствовать строго два файла:
    Malowar_News_Agent_Update.zip
    Malowar_News_Agent_Update.zip.sha256
  ZIP должен содержать Malowar_News_Agent.exe (Windows AMD64).
  Файл SHA256 содержит 64-символьную сумму ZIP (не EXE) в hex-формате.
- Новая версия скачивается ТОЛЬКО с настроенного GitHub Releases.
  Сверяется SHA-256. Программа спрашивает разрешение на установку,
  закрывается, отдельный обновлятор сохраняет старый EXE и копию state.json,
  заменяет EXE и запускает программу. Без согласия обновление не ставится.
- Проверка SHA-256 НЕ является цифровой подписью и не защищает от взлома
  выбранного GitHub-репозитория. Выбирайте только контролируемый репозиторий.
- Автообновление не работает в Portable, без GitHub-репозитория или без
  опубликованного релиза. Первая установка 1.3.3 производится вручную.
- При ошибке замены старый EXE восстанавливается, ошибка записывается в
  Data/updates/update-error.txt. Полный запуск на конкретном ПК нужно
  проверить отдельно. Резервные копии: Data/updates/backups/.

Защита публикаций
-----------------
Пост не публикуется без ручного одобрения, проверки фактов и источников,
трёх-семи изображений и VK-доступа. Ollama не публикует материалы сама.

Проверки в среде сборки: unit-тесты Go, go vet, компиляция Windows AMD64,
JS syntax, API smoke test. Запуск инсталлятора и обновлятора на Windows
в этой среде НЕ проверялся. Прежде чем использовать в рабочем окружении,
протестируйте на резервной копии Data.
