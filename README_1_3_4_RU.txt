MALOWAR NEWS AGENT 1.3.4 (Windows 10/11 x64, тестовая сборка)

Что нового:
- Новая эмблема-маскот в заголовке, favicon, ярлыке Windows и списке программ.
- Если в настройках уже включены Ollama и локальный ИИ, News Agent
  пытается запустить локальный сервер Ollama при открытии программы.
- ИИ-модель qwen3:14b не загружается в видеопамять до генерации поста.
- Можно закрыть PowerShell; отдельное окно терминала для Ollama не нужно.

Установка:
1. Закрой News Agent через кнопку «Выход»; сохрани резервную копию Data.
2. Запусти Setup.exe и выбери ту же папку установки, что у версии 1.3.3.
3. Проверь настройки локального ИИ и работу иконки ярлыка.
4. Закрой приложение и заверши Ollama в трее. Повторно открой News Agent.
   Если локальный ИИ включён, программа должна снова запустить Ollama.
5. Нажми «Проверить Ollama»; затем сгенерируй тестовые два варианта поста.

Обновление через GitHub:
- В настройках по-прежнему нужно указать ПОДТВЕРЖДЁННЫЙ официальный
  публичный репозиторий GitHub Releases, например owner/repo. Без него
  кнопка «Обновления» не может загрузить релиз.
- ZIP и SHA256 формируются при сборке. SHA256 защищает от повреждения
  загрузки, но не является криптографической подписью издателя.
- Пока официальный канал не опубликован, обновление 1.3.3 -> 1.3.4
  делается установщиком. Проверка автоматического обновления через интернет
  требует публикации нового релиза в контролируемом GitHub-репозитории.
- Программа сохраняет каталог Data при обновлении; инсталлятор делает
  копию state.json. Рекомендуется отдельная резервная копия Data.

Никакие VK-посты не публикуются автоматически без ручного одобрения.
