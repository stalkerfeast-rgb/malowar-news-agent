MALOWAR NEWS AGENT 1.3.6 — «РЕДАКЦИОННЫЙ ЦЕНТР»

Новые возможности:
1. Разделы: Paradox, крупные стратегии, модификации, подтверждённые инди, инди-кандидаты.
2. Фильтры событий: релиз, ранний доступ, DLC, патч, мод и анонс. Дополнительный фильтр работает совместно с рубрикой.
3. Новость хранится единожды. Мод Stellaris может одновременно входить в Paradox и «Модификации».
4. Ручная редакционная классификация каждой новости и привязка модификации к игре.
5. Редактируемые списки основных серий и подтверждённых инди-игр в «Настройках».
6. Steam Workshop: поддержка необязательного третьего столбца ID|Название мода|Игра.
7. Версия 1.3.6 готова к установке штатным обновлятором из версии 1.3.5.

КАК ОБНОВИТЬ С 1.3.5
1. Не удаляй предыдущую установленную версию. Репозиторий обновлений должен быть настроен: stalkerfeast-rgb/malowar-news-agent.
2. Опубликуй релиз v1.3.6 в официальном GitHub с двумя файлами: Malowar_News_Agent_Update.zip и Malowar_News_Agent_Update.zip.sha256.
3. В программе нажми «Обновления» → «Проверить обновления» → подтверди установку.
4. Установщик/обновлятор сохраняет Data и резервирует state.json. Для подстраховки можно скопировать папку Data самостоятельно.
5. Проверь номер 1.3.6, рубрики, новые настройки и работу превью изображений.

Особенности:
- При миграции база переводится с версии 5 на 6 без изменения записей, одобрений, медиа или расписания.
- Неподтверждённая новая игра не объявляется инди автоматически: это «Инди-кандидат».
- Старые источники Workshop продолжают работать в формате ID|Название. Для привязки к игре добавь третий столбец или укажи игру в редакторе материала.
- Реальные DLL/EXE и установка требуют тестирования на Windows. Linux-кросс-сборка не заменяет проверку на ПК пользователя.
- Программа ничего не публикует без явного ручного одобрения.
- SHA-256 подтверждает целостность скачанного ZIP, но не является цифровой подписью издателя.
