MALOWAR NEWS AGENT 1.3 — WINDOWS BETA
====================================

Что добавлено после 1.2
-----------------------
* Календарь публикаций по московскому времени (UTC+3).
* Назначение точной даты или ближайшего свободного слота; интервалы между постами >=30 минут.
* Изменение времени, отмена и статус «Пропущена». Пропущенные после выключения ПК посты НЕ публикуются задним числом.
* Ручное подтверждение публикации и проверка фото; автоматическое размещение только постов, для которых редактор назначил слот.
* Журнал редакционных действий и локальная статистика материалов; необязательная ручная загрузка счётчиков VK через wall.getById при доступе.
* Срочные новости по настраиваемому порогу приоритета, уведомления в окне и опциональные уведомления браузера.
* Сравнение текста новой и предыдущей версии описания модификации (это НЕ официальный changelog).
* ИИ-редактор учитывает до трёх ранее вручную проверенных постов как примеры стиля, но не как факты.
* Расширена глубина поиска каталога Steam; мониторинг остаётся выборочным и зависит от доступности источников.

Установка / обновление
---------------------
1. Закрой старую версию кнопкой «Выход» в окне приложения. Не оставляй её работающей в фоне.
2. Сделай копию папки Data (состояние, черновики и изображения).
3. Запусти Malowar_News_Agent_1_3_Setup.exe и выбери прежнюю папку установки, если обновляешься.
4. Запускай приложение через ярлык. Удаление доступно в «Установленных приложениях» Windows.
5. Данные сохраняются при удалении, если не выбрано удаление данных.

Как пользоваться расписанием
----------------------------
1. Открой новость, проверь первоисточник, даты, текст и 3–7 официальных изображений.
2. Отметь проверку, нажми «Одобрить». На этом этапе публикации НЕТ.
3. Назначь время в МСК или нажми «В ближайший слот».
4. Открой «Календарь», чтобы проверить очередь и перенести запись.
5. В назначенный момент программа должна быть открыта, интернет и VK подключены (токен в памяти).
6. После подтверждения поста VK агент отправляет ссылки отдельным первым комментарием. При неопределённом статусе НЕ повторяет публикацию вслепую.
7. Если ПК был выключен, VK не подключён или слот устарел, пост получает «Пропущена» и ждёт нового решения.

Охват источников
----------------
Steam News для списка игр и найденных стратегий, выбранные Steam Workshop, GitHub Releases и добавленные RSS/Atom.
Абсолютно ВСЕ стратегии и моды обнаруживать невозможно: часть публикаций не имеет публичного RSS/API, Steam не индексирует весь рынок.
Для новостей вне Steam может не хватать официальных изображений; такие посты требуют добавления изображений вручную.

ИИ редактор
-----------
Ollama локально или OpenAI API через отдельный ключ (не входит в подписку ChatGPT).
ИИ может ошибаться, даже если использует только оригинальный текст. Сверяй первоисточник перед одобрением.
Ссылки в теле VK-поста удаляются и добавляются в поле первого комментария.

Данные и конфиденциальность
--------------------------
В версии 1.3 используется локальный Data/state.json с резервной копией, а не SQLite.
API ключи и VK токен не сохраняются на диск, поэтому после перезапуска их нужно подключить заново.
При установке в выбранную папку локальные данные лежат в её Data.
Без установки данные по умолчанию в %LOCALAPPDATA%\MalowarNewsAgent\Data.
Ни один пост или комментарий не отправлялся во время тестирования сборки.

Нереализованные этапы большой дорожной карты
---------------------------------------------
Полная синхронизация с облачной задачей, полноценный SQLite-хранилище, всесторонний анализ трендов YouTube/VK,
гарантированное извлечение официальных кадров по каждому моду, и автономная публикация при выключенном ПК.
Эти возможности требуют отдельного облачного сервиса/подключения и дальнейших проверок API.

Тестирование
------------
Сборка Go, Windows EXE, синтаксис интерфейса, сценарий локального планирования и отмены расписания проверены.
Реальные Windows-окна, инсталляция/удаление на пользовательской Windows, сетевой обход, живые VK/Steam API и публикация НЕ проверены.
Приложение без цифровой подписи, Windows может предупредить об этом.
Исходники включены отдельно для GitHub, в том числе тесты. Для работы приложения GitHub не требуется.


Версия 1.3.2 — локальный ИИ по запросу
- Кнопка «ИИ: включён/выключен» в шапке программы. Нажатие «Включить» требует установленной и доступной Ollama.
- Модель по умолчанию: qwen3:14b (предварительно: ollama pull qwen3:14b).
- При создании поста модель загружается в VRAM; параметр Ollama keep_alive=0 выгружает её после ответа.
- Выключение ИИ дополнительно отправляет запрос на выгрузку выбранной модели и не останавливает другие программы или службу Ollama.
- Мониторинг Steam/Workshop, очередь VK и одобрение работают без локального ИИ.
- Если Ollama выключена или нужная модель не скачана, программа покажет инструкцию и не начнёт генерацию.
- Встроенная проверка доступности Ollama: Настройки → Проверить Ollama.
- Это управление только локальной моделью; оно не управляет драйверами NVIDIA, не меняет настройки Windows и не завершает службу Ollama.

Примечание: включение локального ИИ не запускает автоматическое переписывание. Чтобы использовать Qwen3:14b, выбери новость и нажми «ИИ: перевести и интересно переписать». При этом память освобождается после завершения.

Версия 1.3.2 — два варианта русских постов
---------------------------------------
* Локальная Qwen3 14B через Ollama /api/chat создаёт в одном запросе короткий и развёрнутый варианты.
* В редакторе можно переключаться между ними, но выбор заменяет текущий черновик. Сохрани свои правки перед переключением.
* Включено think=false для отключения размышлений, keep_alive=0 для выгрузки модели после генерации.
* ИИ получает только короткое описание новости, а не всю страницу: автоматической проверки первоисточника НЕТ.
* Программа помечает подозрительные числа, даты и отдельные заявления, которых нет в полученном описании.
* Предупреждения — лишь эвристика: отсутствие предупреждений не означает достоверность.
* Каждый созданный черновик остаётся непроверенным. Для одобрения по-прежнему нужны ручная проверка и 3–7 изображений.
* Ссылки остаются в первом комментарии VK.
* OpenAI API сохраняет прежний режим одной версии текста. Два варианта пока предназначены для локальной Ollama.

Проверка: Ollama должна быть запущена, модель установлена через ollama pull qwen3:14b.
Проверка на реальной Windows/RTX 5080 и публикация в VK НЕ выполнялись в среде сборки.
