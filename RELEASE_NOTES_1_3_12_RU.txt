Malowar News Agent 1.3.12 — VK: прозрачная отложка

Что исправлено
• После ручного одобрения новости при включённом VK Postponed Mode она сначала получает локальный статус vk_pending, затем агент отправляет её в VK через wall.post с publish_date.
• «В отложке VK» показывается только после подтверждения post_id в ответе VK. В ленте и карточке отображаются четыре этапа: одобрено, отложено (ID VK), опубликовано, первый комментарий с источниками.
• Фильтр «В расписании» включает отложенные записи; появился отдельный «Отложка VK · статусы», счётчик очереди, принятых постов и ошибок.
• Можно явным нажатием отправить уже одобренный старый черновик в отложку. Ретроспективной массовой автопубликации нет.
• Назначение времени для одобренного поста при включённой отложке теперь отправляет его в VK, а не создаёт только локальное расписание.
• Если VK явно вернул API-отказ (например, недостающие права), показывается конкретная ошибка, а не ложная неопределённость. После сетевого сбоя на этапе wall.post автоматического повтора нет: сначала проверь отложку в VK, чтобы избежать дублей.
• Посты по-прежнему требуют ручной проверки источника, 3–7 фотографий и 4–5 хэштегов, включая название игры одним словом.
• Первый комментарий с источниками создаётся только после подтверждения выхода записи на стене. Агент должен работать с токеном VK для добавления комментария.

Сохранено: редакционный центр, релизный радар 35/30/25/10, гибридные стратегии, каталог ачивок и редактор обложки, существующие Data и черновики.
Важно: этот патч не добавляет 47 ещё неутверждённых графических PNG наград.

Проверено локально: тесты Go, go vet, сборка Win64, проверка логики VK на эмуляции ответов API и JS syntax. Реальная публикация в сообществе VK и установка на пользовательском Windows не выполнялись.
