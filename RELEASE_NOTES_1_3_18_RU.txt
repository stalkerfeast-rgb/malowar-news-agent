Malowar News Agent 1.3.18 · Улучшенная передача фотографий в VK

- При ручном одобрении News Agent переносит текст и пытается прикрепить 3–7 изображений одним нажатием.
- Добавлен поиск скрытых и динамических полей загрузки VK; допускаются варианты без атрибута accept и поля, появляющиеся после нажатия «Фото».
- Добавлен управляемый выбор файлов через стандартное окно Edge (DevTools Protocol).
- Если VK поддерживает перетаскивание фотографий, добавлен защищённый резервный способ с проверкой того, что сайт принимает событие DragOver.
- Передача изображений считается успешной, если Edge принял выбор файлов; фактическое завершение загрузки на сервер VK пользователь проверяет по миниатюрам.
- Прежний ручной перенос файлов из подготовленной папки сохранён.
- Текст в чужом черновике не заменяется; автоматическая публикация не производится.
- Плиточное представление остаётся стандартным и зависит от VK.
- Сохранены настройки, черновики, награды, профиль Edge и DPAPI-токены.
- Установщик предлагает E:\Агент при наличии диска E:, иначе локальный каталог Windows.

Проверки: go test, go vet, локальный тест Chromium для поля файлов, динамического окна выбора и безопасного перетаскивания. Редактор реального VK на Windows ещё не тестировался.
