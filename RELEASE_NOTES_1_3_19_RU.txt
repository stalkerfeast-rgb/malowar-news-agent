Malowar News Agent 1.3.19 — Одна кнопка для подготовки записи VK

Что нового:
- «Открыть запись и заполнить VK»: одним нажатием открывает отдельный Edge, пытается нажать «Создать запись», вставляет текст и передаёт 3–7 фотографий.
- Если редактор уже открыт, повторно его не открывает.
- Не заменяет чужой текст, останавливается при неоднозначных кнопках создания записи.
- Публикацию и время отложенной записи редактор подтверждает вручную в VK.
- Сохранён проверенный в версии 1.3.18 ручной резерв: кнопка «Перенести текст и фото», копирование текста и папка изображений.
- Установка по умолчанию E:\Агент при наличии диска E; папка Data и профиль Edge VK сохраняются.

Проверки: go test ./..., go vet ./..., node --check, тесты работы с редактором и изображениями на локальном Chromium, сборка Windows x64.
Ограничение: интерфейс реального vk.ru не проверен в этой среде. Если автопоиск кнопки не сработает, создай запись вручную и используй рабочий механизм 1.3.18.

Важно: не публикует без подтверждения; нет VK API и первых комментариев.
