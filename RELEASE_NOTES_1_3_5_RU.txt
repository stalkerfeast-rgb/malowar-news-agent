Malowar News Agent 1.3.5 — исправление изображений

Что исправлено:
1. Локальные изображения снова отображаются в галерее: политика безопасности разрешает blob: только для img-src (внешние сайты по-прежнему не разрешены).
2. Ошибка отображения показывает объяснение вместо пустого прямоугольника.
3. Временные blob-ссылки освобождаются при загрузке картинки или переходе к другой новости.
4. Подбор обложки и скриншотов выполняется параллельно (до четырёх запросов одновременно); порядок официальная обложка → скриншоты сохранён.
5. Маскот и автоматический запуск Ollama из 1.3.4 сохранены.

Установка:
- Полностью закрой Malowar News Agent кнопкой «Выход».
- На всякий случай скопируй папку Data.
- Установи 1.3.5 в ту же папку, что 1.3.4.
- Открой новость, где раньше вместо картинок были пустые прямоугольники: изображения должны появиться без повторного скачивания.
- Если потребуется, нажми «Подобрать: обложка → геймплей».
- Никакие новости не публикуются без твоего одобрения.

Проверки: go test ./..., go test -race ./..., go vet ./..., node --check, кросс-сборка Windows x64, проверка содержимого ZIP. Windows UI не протестирован на компьютере пользователя.

Автообновление через GitHub Releases начнёт работать после привязки официального репозитория, сейчас при переходе с 1.3.4 требуется один раз запустить установщик.
