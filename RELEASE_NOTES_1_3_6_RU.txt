Malowar News Agent 1.3.6: Редакционный центр

• Добавлены вкладки Paradox, крупные стратегии, модификации, инди, инди-кандидаты и релизы.
• Тип события отделён от игровой рубрики: один материал может входить в несколько подборок без дублирования.
• В редакторе можно назначить рубрику и указать игру, для которой создан мод.
• В настройках появились списки основных игр и подтверждённых инди.
• Поддержка формата Steam Workshop ID|Название|Игра.
• Сохранена работа локальной Qwen3 14B, предпросмотра медиа, обложек и подтверждения VK.
• Подготовлен пакет обновления для проверки перехода с 1.3.5 через GitHub Releases.

Первый тест автообновления на Windows ещё не подтверждён. Перед установкой рекомендуется копия Data.
