Malowar News Agent 1.3.7 — «Релизный радар»

Новое:
• Вкладка «Релизный радар»: топ-15 ожидаемых стратегий, упорядоченных по дате выхода.
• Автопоиск грядущих стратегий в Steam (best-effort) и ручное добавление AppID игр для наблюдения.
• Редакторские настройки: подготовка за 5 дней, топ-15, предварительные анонсы, релизные посты, инди.
• Публикация только после одобрения! Радар не публикует автоматически непроверенные анонсы.
• При подтверждённой точной дате создаётся отдельный черновик за 5 дней и в день фактического выхода.
• Steam является источником даты: «Скоро»/месяц/квартал не создают таймер и пост о состоявшемся релизе.
• Поддержка русского языка: «есть», «не заявлен в Steam», «не подтверждён»; без списка остальных языков.
• Опциональный рерайт Qwen3 14B (использует существующее разрешение на локальный ИИ и AutoRewrite).
• Официальная страница Steam в комментарии, обложка и скриншоты из существующего модуля изображений.
• Защита от дублирующих постов, переносов даты и повторных публикаций.
• Сохранение новостей, настроек, Data и канала обновлений при переходе с 1.3.6.

Использование:
1. В установленной версии 1.3.6 уже должен быть настроен канал обновлений stalkerfeast-rgb/malowar-news-agent.
2. Опубликуйте GitHub Release v1.3.7, прикрепив Malowar_News_Agent_Update.zip и Malowar_News_Agent_Update.zip.sha256.
3. В программе нажмите «Обновления», затем «Проверить обновления» и подтвердите установку.
4. После перезапуска выберите «Релизный радар · топ-15». Нажмите «Проверить ожидаемые релизы».
5. В «Настройках» можно менять топ и горизонт планирования и добавлять конкретные Steam AppID.
6. Для автоматической переработки описаний подключите Ollama, включите локальный ИИ и «Автоматически готовить черновики через ИИ».

Ограничения:
• Реальный поиск Steam зависит от доступности store.steampowered.com и региональных ограничений.
• Steam не предоставляет стопроцентную гарантию точной даты/времени; автоматическое подтверждение касается страницы конкретного приложения.
• Qwen3 14B может ошибаться: факты перед публикацией нужно проверить.
• Публикация в VK не выполняется автоматически без предварительного одобрения. Для отправки нужен действительный VK-токен.
• Обновление из GitHub требует работающего локального News Agent 1.3.6 и проверки на Windows.
