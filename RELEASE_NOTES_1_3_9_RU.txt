MALOWAR NEWS AGENT 1.3.9 — MALOWAR AWARDS
============================================

Что нового:
* Утверждённые награды «Скрытая жемчужина», «Живой мир», «Сомнительно» встроены в редактор карточки новости без изменения дизайна.
* Кнопка «Награды на обложке» в разделе изображений. Плашки можно включать, выключать, передвигать мышью и менять в размере прямо на превью 1280×720.
* Автоматическая расстановка: одна справа внизу, две справа по вертикальному центру с отступом, три справа сверху, по центру и снизу. Можно настроить всё вручную.
* Отражение всей исходной обложки или отдельно загруженного PNG-персонажа, настройка размера и положения персонажа.
* Сохранение в первом изображении редакционной карточки. Исходный баннер сохранён отдельно и доступен для повторного редактирования/восстановления.
* Сохранение раскладки в локальном state.json, повторное редактирование после перезапуска.
* При изменении обложки прежнее одобрение сбрасывается. Публикация VK не происходит автоматически.
* Код интегрирован непосредственно в Go-приложение v1.3.8, функции релизного радара и редактора сохранены.

Обновление установленной версии 1.3.8:
1. В News Agent нажми «Выход». Не оставляй прежний экземпляр запущенным.
2. Для дополнительной безопасности скопируй папку Data.
3. Запусти Malowar_News_Agent_1_3_9_Setup.exe и выбери ту же папку установки, что и для 1.3.8.
4. Открой нужную новость → «Официальные изображения» → «Награды на обложке».
5. Перетащи награды мышью, настрой отражение при необходимости, нажми «Сохранить награды в карточке новости».
6. Сверь сохранённую первую картинку и заново одобри новость.

ВАЖНО:
* Installer обновляет бинарный файл, сохраняет Data и предварительно копирует state.json в Data/updates/backups.
* Не переносите отдельный HTML-редактор. Он уже интегрирован в приложение.
* При отражении целой картинки надписи тоже зеркалятся. Для обложек с текстом используйте отдельный PNG-слой персонажа.
* Из исходного утверждённого макета награды вырезаны в PNG с прозрачным фоном. Новый стиль не генерировался.
* На реальной Windows 11 и с реальной публикацией VK в этой среде не тестировалось.
* Установщик без цифровой подписи может вызывать предупреждение SmartScreen.
* Репозиторий GitHub main не изменён; для автообновления требуется выпуск релиза в GitHub.

Редакционная доработка 1.3.9 (24 ноября 2026)
--------------------------------------------
* Уточнены инструкции Ollama/Qwen3: первая строка содержит название игры один раз,
  первый абзац сообщает суть новости без повторного представления игры и жанра.
* Развёрнутый вариант: при достаточно подробном первоисточнике ориентир 700–1100 знаков
  и 3–5 содержательных абзацев с подтверждёнными фактами, без искусственного растягивания.
* Короткий вариант: при подробном источнике ориентир 400–650 знаков.
* Для OpenAI-редактора применены те же принципы: факты, ясная подача, без тавтологии.
* Убирается только очевидное пустое определение жанра в начале абзаца, если далее
  остаются содержательные сведения. Фактические предложения не удаляются автоматически.
* Добавлены подсказки редактору о неудачном вводном абзаце, слишком коротком
  развернутом посте и недостаточности исходных данных.
* Исправлены повторные названия игр в шаблонах релизного радара и исходных черновиков.
* Старые посты и утверждённые публикации не меняются. Редактура применяется при новой генерации.
* Нет автопубликации: фактчек и ручное одобрение остаются обязательными.
* Без изменения формата state.json, изображений и версии автообновлятора.
