Источники и публикации

Одна строка = один источник. Можно добавить свои игры и моды. Для проверки выбери «Проверить сейчас».

Игры Paradox определяются по отдельному справочнику. Всё остальное без подтверждения попадает в «Инди-кандидаты». Категорию каждой новости можно изменить вручную.

Релизный радар · Steam

Отслеживает ближайшие выходы стратегий. Создаёт черновик за 5 дней до точной даты и отдельный черновик, когда Steam подтвердит релиз. Окончательное одобрение и отправка в VK остаются за тобой.

Только точные даты из Steam запускают пятидневный отсчёт. Если русский язык не указан, агент пишет «не заявлен», но не делает вид, что перевода точно нет.

Для передачи программы другому редактору укажи адрес его сообщества VK. Токены не нужны.

Режим публикации: после ручной проверки. Даже с автоматической отправкой агент публикует только те новости, которые ты лично одобрил, отметил как проверенные и снабдил 3–7 изображениями.
VK Publisher: после одобрения News Agent готовит локальный пакет: текст и 3–7 фото. Открой сообщество в отдельном окне Edge, вставь текст и загрузи фото через официальный редактор VK, затем лично выбери отложенную публикацию. Автоматическая отправка через VK API выключена.

Ни одобрение, ни подготовка пакета не публикуют запись. Первый комментарий с источниками больше не создаётся. Время выбирается вручную в VK.

Русский ИИ-редактор: переводит и пересказывает новости. Пишет только по полученному тексту, не подтверждает факты. Нужна своя Ollama или отдельный ключ OpenAI API; подписка ChatGPT не даёт API-доступ автоматически.
При включённом локальном ИИ News Agent запускает Ollama при необходимости. Модель загружается только во время создания поста и выгружается после ответа. Выключение остановит новые задания ИИ и попытается освободить память, но не закроет саму Ollama.

Модель загружается только при генерации.

Нужен публичный GitHub Releases с Malowar_News_Agent_Update.zip и файлом .zip.sha256. Если канал не задан, обновления не скачиваются.

VK Publisher · Malowar Gaming

 
Текст и фотографии подготовлены локально. Автоперенос экспериментальный и может потребовать открыть редактор и кнопку «Фото» в VK. Пока ты не сохранил запись на сайте VK, публикации нет. Авторизация в отдельном окне Edge сохраняется в профиле Windows.

 

 
 

 
Основная кнопка «Открыть запись и заполнить» сама пытается открыть редактор и перенести материалы. Если VK изменил интерфейс, используй проверенную кнопку «Перенести текст и фото», предварительно открыв создание записи вручную. Дату и окончательную публикацию подтверждаешь ты.

 

 
Эта отметка ручная, не является подтверждением VK API. Если сомневаешься, сначала проверь отложенные записи сообщества.
